# **기상 관측 시계열을 활용한 안개 강도 분류**


_2025년 1학기 **데이터마이닝** · 6인 팀 프로젝트_

2024 날씨 빅데이터 콘테스트 과제 2 「기상 특성에 따른 안개 발생 진단」 수상작 개선 과제이다. <br><br> 당시 최우수상을 받은 ‘갈라진 하늘’ 팀의 2-Stage 모델을 분석하고,<br> 연속 관측을 입력으로 받아 네 등급을 한 번에 분류하는 TCN(Temporal Convolutional Network)을 실험했다.
</div>


## 분석 질문

기존 모델은 먼저 안개 유무를 판단하고, 안개로 분류된 관측에 대해서만 강도를 예측한다.<br>
첫 단계에서 놓친 안개는 두 번째 단계에서 강도를 판별할 기회도 사라진다.<br>
**연속된 기상 관측을 함께 보고 드문 안개 등급의 학습 비중을 높이면, 실제 안개를 얼마나 포착할 수 있을까? 그 과정에서 안개가 없는 시점의 오경보는 얼마나 생길까?**

## 중간 제안에서 최종 실험까지

| 설계 결정 | 중간 발표에서 검토한 방법 | 최종 발표에 기록한 구현 |
| --- | --- | --- |
| 안개 누락 | 1단계 판정 임계값을 F2 기준으로 조정하고 안개 확률을 2단계에 전달 | TCN으로 4개 등급을 직접 분류. Focal Loss와 가중 샘플링으로 소수 등급의 학습 비중 조절 |
| 시간 정보 | 10분·20분·1시간 전 관측값을 시차 변수 후보로 선정 | 연속 관측 24개와 36개(4시간·6시간)를 입력 창으로 검토. 창의 마지막 시점이 분류 대상 |
| 기상 변수 | 이슬점 편차 등 파생변수, 기온·지면온도의 PCA, 이상치 보간 제안 | 학습 자료로 PCA를 적합하고, 일사량·지면온도·풍속을 지역·계절별로 나눠 Isolation Forest와 선형 보간 적용 |

검증 자료의 평균 CSI를 기준으로 채널과 커널 조합을 비교했다. <br>

## 결과 - 안개 포착과 오경보

[최종 발표](final.pdf) 16쪽의 TCN 혼동행렬에서 등급 1–3은 안개, 4는 안개 없음이다. 

| 질문 | 계산 | 결과 |
| --- | ---: | ---: |
| ➀ 실제 안개를 안개로 인식했는가? | 6,318 / 6,428 | 98.29% |
| ➁ 실제 안개의 강도까지 정확히 맞혔는가? | (807 + 838 + 925) / 6,428 | 39.98% |
| ➂ 안개가 없었는데 안개로 판단했는가? | 237,473 / 595,858 | 39.85% |

안개 유무만 보면 놓친 관측은 110건이었다. 그러나 실제 안개의 강도까지 맞힌 비율은 약 40%였고, 안개가 없던 시점에도 약 40%에서 경보에 해당하는 예측을 냈다. 안개를 놓치는 비용과 오경보로 인한 부담을 함께 고려할 때, 소수 클래스 탐지율 하나만으로 모델을 선택하기 어렵다는 점을 확인했다.

_4×4 혼동행렬_ <br><br>

최종 발표에 기록된 TCN의 전체 정확도는 **59.9308%**, Macro F1은 **21.1048%**, 공모전 방식 CSI는 **1.05**다. 비교 자료의 두 혼동행렬은 관측 건수가 달라 모델 변경에 따른 향상률을 계산하지 않았다. 여러 변경을 함께 적용했으므로 TCN, 손실 함수, 샘플링 각각의 기여도도 이 결과만으로 분리하기 어렵다.
