**IBA · 지능형 경영 데이터 분석 학술동아리 11기 활동**

4인 팀으로 진행한 두 프로젝트에서 변수 EDA, 모델링, 코드 파일 작성을 주로 맡았다.

팀원들과 변수별로 데이터를 살펴 전처리 가설을 세우고, 같은 조건에서 모델을 비교해 어떤 처리를 적용할지 결정했다.
<br><br>

| 프로젝트 | 분석 질문 | 주요 결과 |
| --- | --- | --- |
| [분류](credit-risk/) - 독일 대출 고객 신용위험 분류 | 전처리와 모델 튜닝은 어느 등급의 예측을 개선하는가? | 로지스틱 회귀를 튜닝한 뒤 양호 등급 F1은 높아졌지만 위험 등급 재현율은 낮아졌다. |
| [회귀](used-car-price/) - 영국 중고차 가격 예측 | 연비를 구간으로 요약해도 가격 예측에 필요한 정보가 남는가? | 세금 처리와 희소 차종 통합 조건을 고정해 비교했을 때 연비 구간만 사용한 네 조합 모두에서 원래 연비를 함께 사용하면 검증 오차가 줄었다. |
